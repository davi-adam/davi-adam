## Sobre mim

O que mais me interessa em desenvolvimento é entender o que está por trás de cada solução: como as peças se conectam, o que acontece por baixo do código, e como uma ideia sai do zero até funcionar de verdade.

Estudo full stack, com o momento atual puxando mais para TypeScript, React, Next.js e Tailwind, sem deixar de lado Python, Java e C#, que seguem como base. Aprendo testando, quebrando as coisas pra entender o porquê, e evoluindo a partir de projetos autorais.

## Conhecimentos técnicos

**Frontend**
Componentização e hooks com React, roteamento e renderização híbrida (SSR/SSG) com Next.js, estilização utilitária com Tailwind CSS, tipagem estática com TypeScript aplicada a interfaces e contratos de API.

**Backend & linguagens**
Python orientado a objetos, construção de APIs e automações, integração com bancos de dados. Java com foco em POO e estruturas de dados. C# com fundamentos de sintaxe e paradigma orientado a objetos.

**Banco de Dados & SQL**
Modelagem relacional, consultas avançadas, uso prático de PostgreSQL, MySQL e SQLite, além de noções de NoSQL.

**Git & versionamento**
Fluxo de branches, pull requests, resolução de conflitos e boas práticas de trabalho colaborativo em repositórios.

**DevOps & Cloud (AWS)**
Primeiros passos com containers Docker, conceitos de pipelines de CI/CD e deploy básico de aplicações em serviços AWS.

**IA aplicada**
Engenharia de prompts e uso de IA generativa integrados ao fluxo de estudo e desenvolvimento.
